# PRD：全站主题色更新（静态网页）

## 背景与目标
- 当前页面整体以粉色系为主（渐变背景、按钮、标题栏、阴影与边框均为粉色系硬编码）。
- 目标：将“整个项目”的主题色替换为新的统一色系，并确保后续可通过少量变量快速换肤。

## 范围
### In Scope
- 将现有 CSS 中与主题相关的颜色（主色、强调色、浅色背景、描边、阴影色）抽象为 CSS 变量。
- 将页面中所有引用主题色的硬编码值替换为变量引用。
- 提供一套新的默认主题色方案（可一键改动变量完成换肤）。

### Out of Scope
- 业务逻辑改动（script.js 行为不变）。
- 结构性重做布局（HTML 结构保持不变）。
- 字体与文案整体重设（除非为配合主题色必要的可读性调整）。

## 用户故事
- 作为维护者，我希望只改一处（变量）就能替换全站主题色，避免到处找十几个 hex 值。
- 作为用户，我希望主题色更统一，按钮/标题/进度条/卡片强调色一致且清晰。

## 需求（功能性）
1. 提供 `:root` 级别的主题变量（至少包含：主色、主色渐变两端、浅底色、描边色、阴影色、强调文字色）。
2. 页面关键区域使用主题变量：
   - Header 渐变与阴影
   - 主按钮渐变与阴影
   - 次按钮描边与文字色
   - 单词标题文字色、统计数字、列表高亮文字
   - 卡片阴影、边框、浅底块背景、进度条背景/填充
3. 保持对比度与可读性：正文文字（#333/#666）不因主题更换而变得不可读。

## 默认主题色方案（可调整）
- 主题命名：Aurora Teal（极光青绿）
- 主色渐变：`#14b8a6` → `#0ea5e9`
- 强调文字色：使用主色或更深一档（例如 `#0f766e`）
- 浅底：偏冷浅色（例如 `#ecfeff` / `#f0f9ff`）
- 阴影：由主色推导的半透明色（例如 `rgba(20, 184, 166, 0.25)`）

## 验收标准
- 页面中不再出现粉色主题硬编码（例如 `#ff69b4/#ff1493/#ffeef8/#fff5f8` 等）作为主题用途；相应位置改为变量引用。
- Header、按钮、进度条、强调文字与卡片装饰色均呈现新主题色系，且视觉一致。
- 只修改 `:root` 的主题变量即可完成换肤（无需全局搜索替换多个颜色值）。

## 风险与注意事项
- 部分颜色既用于主题也用于通用中性色（例如正文 #333/#666），需避免误替换导致可读性下降。
- 阴影与透明色需要与新主色系协调，避免过脏或对比不足。
