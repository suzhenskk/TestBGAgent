# 📝 ToDoList 应用

一个简洁好看的待办清单网页应用，支持本地持久化保存。

## 功能

- 添加任务
- 勾选完成/取消完成
- 删除单个任务
- 按状态筛选（全部 / 未完成 / 已完成）
- 一键清除已完成任务
- 实时统计任务数量
- 本地存储（刷新页面不丢失）

## 使用方式

1. 直接打开 `index.html`
2. 在输入框输入任务并点击“添加”
3. 通过复选框标记完成状态
4. 可按筛选按钮查看不同状态任务

## 文件结构

- `index.html`：页面结构
- `styles.css`：页面样式
- `script.js`：业务逻辑与本地存储
