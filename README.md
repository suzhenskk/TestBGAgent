# Flappy Bird（纯前端版）

一个使用 **HTML + CSS + JavaScript + Canvas** 实现的 Flappy Bird 小游戏。

## 玩法

- 点击“开始 / 重新开始”开始游戏
- 按 **空格** 或点击画布让小鸟上升
- 穿过水管缝隙获得分数
- 撞到水管或飞出边界则游戏结束

## 特性

- 本地最高分（LocalStorage）
- 简洁 UI，支持桌面和移动端点击操作
- 无依赖，直接打开 `index.html` 即可运行

## 文件结构

- `index.html`：页面结构
- `styles.css`：样式
- `script.js`：游戏逻辑
